# 0.8.0

This release adds personal Govee, Tuya Smart and LSC Smart Connect accounts, capability-based device controls, and supported smart-plug readings.

- Sign in with email and password, choose your account country from a dropdown, and display partially hidden account emails.
- Refresh linked accounts, local discovery and saved device states together with Find Devices.
- Show power, brightness, RGB and white-temperature controls according to each light, switch or plug's capabilities.
- Display supported plug power, voltage and current readings, with five-second refresh while open and monthly/daily energy history where available.
- Improve device icons, card sizing, inspector alignment and compact layouts throughout the app.
- Fix native thread cleanup during rapid Govee brightness/power changes and Windows startup affected by bundled ICU libraries.
- Add persistent crash logs, an Open logs folder action, and iDotMatrix clock, rotation, countdown and scoreboard tools.

Tuya/LSC password login needs the matching Android app package once. Cloud connections provide manual control; screen/music sync requires a supported local connection. Features and readings vary by model and firmware. Linux screen sync requires X11, and the AppImage requires glibc 2.35+.
