# LumiSync 0.8.0

Control devices through your own Govee, Tuya Smart and LSC Smart Connect
accounts, see supported plug readings, and use device controls that match the
hardware. This release also improves window sizing and fixes a crash during
rapid Govee brightness and power changes.

## Accounts and wireless control

- Sign in with Govee, Tuya Smart or LSC Smart Connect email and password.
  Govee API keys and Tuya/Smart Life QR authorization remain available.
- Choose your account country from a dropdown. LumiSync suggests the local
  region and remembers your choice separately for each provider.
- Account labels mask email addresses. Saved sessions and application login
  configuration use the operating system's credential store; passwords are
  not saved in device settings.
- Find Devices refreshes linked accounts and saved device states alongside
  local Wi-Fi and Bluetooth discovery. Authorized Tuya local keys can be
  matched to discovered local devices.

## Device controls and readings

- Light switches and plugs show their supported power controls. Brightness,
  color and white-temperature controls appear only when supported.
- Device icons and type labels distinguish LED strips, matrix panels, wall
  switches and smart plugs.
- Supported Tuya/LSC plugs show reported watts, volts and amps, with readings
  requested immediately and every five seconds while the device is open.
  Monthly account energy history includes daily values where available.
- iDotMatrix Panel Tools add clock/time, rotation, countdown and scoreboard
  controls alongside drawing and animation support.

## Interface and reliability

- Device cards fill balanced columns. Opening the inspector keeps the page
  heading and buttons in place and aligns the inspector with the cards.
- Compact layouts improve account forms, device controls, Monitor/Music Sync,
  Draw, Settings, Add Device and Panel Tools. Essential actions stay reachable.
- Keyboard access and focus indicators improve device cards, pixel editing,
  LED mapping and energy-history inspection.
- Fix native thread cleanup that could crash the app during repeated Govee
  controls. Pending changes and status confirmations coalesce, and old status
  replies cannot overwrite newer commands or move a slider while dragging.
- Fix Windows startup affected by an incompatible bundled ICU library.
- Add persistent native crash diagnostics and **Settings → About → Open logs
  folder**. Settings writes use atomic replacement to preserve the previous
  file if saving fails.

## Setup and compatibility

- **Tuya Smart and LSC password login need the matching Android app package
  once.** LumiSync can find a compatible package in Downloads or you can browse
  to it. The Android apps and extracted application configuration are not
  bundled with LumiSync. Each brand uses its own account namespace.
- Account/cloud connections support manual commands and status. Screen and
  music syncing require a supported local connection. Govee LAN provides zone
  streaming; Tuya LAN and iDotMatrix BLE use ambient output where supported.
- iDotMatrix remains a Bluetooth integration. No email-account login or
  generic Wi-Fi control route is provided for those panels.
- Available controls, electrical readings and energy history depend on the
  device schema, firmware and vendor response. A five-second request interval
  does not guarantee the vendor updates its reported measurements that often.
- Vendor account protocols may change. Some accounts require verification
  through the vendor's normal sign-in flow.
- Linux monitor syncing currently requires X11/Xorg; Wayland screen capture
  and Flatpak packaging remain unfinished.

## Downloads

- **Windows:** `LumiSync-Windows-x64-onefile.exe` runs as a standalone file.
  Alternatively, extract `LumiSync-Windows-x64-portable.zip` and keep the
  `_internal` folder alongside `LumiSync.exe`.
- **Linux:** make `LumiSync-x86_64.AppImage` executable and run it. Requires
  glibc 2.35 or newer, such as Ubuntu 22.04+.
- **Python:** install or update with `python -m pip install --upgrade lumisync`.

Close any running LumiSync instance before launching the new version. Existing
settings and remembered account sessions are preserved.

## Verification

The Windows source suite passes 424 tests, including account fixtures, device
capabilities, responsive UI, credential handling and worker cleanup. A real Qt
stress subprocess completes 1,200 rapid control interactions with simulated
device I/O and confirms the final power and brightness state. Windows builds
are checked for startup, integration dependencies and isolated GUI rendering.
CI checks Linux and Windows; the Linux AppImage receives a clean X11 startup
check. These checks do not establish every physical device/firmware combination.
